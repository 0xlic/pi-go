# pi-go

Pi 的双栏项目 / session 切换器。第一版已实现，基于 **Pi 1.1.0、Node.js 22+** 验证。

## 快速试用

在插件目录执行：

```bash
pi -e ./index.ts --go
```

已有会话中，加载插件后输入：

```text
/go
```

若已有会话尚未加载插件，请先全局安装，再在会话内执行 `/reload`。

## 全局安装

```bash
pi install git:github.com/0xlic/pi-go
pi --go
```

从公开 GitHub 仓库安装，Pi 管理远程源码，不依赖本地开发目录。更新插件：

```bash
pi update git:github.com/0xlic/pi-go
```

已有会话更新后执行 `/reload`。可选 shell 别名：`alias pig='pi --go'`。

Pi 扩展原生只支持长参数，因此启动入口是 `--go`，不是 `-g`。不修改系统 `pi` 命令，也不自动安装 shell 包装层。

## 界面和快捷键

```text
项目 › 项目名称 / 目录路径      │ 会话 › 会话名称
Tab 切换 · ↑↓ 选择 · Enter 打开 · Esc 取消
Ctrl+P pin · Ctrl+R 项目重命名 · Ctrl+Y 复制项目路径
───────────────────────────────┼──────────────────────
所有项目                       │ ＋ 新建会话
★ pi-go                        │ ★ 交互设计
  another-project              │   修复搜索
```

| 按键 | 功能 |
|---|---|
| Tab / Shift+Tab | 切换活动栏和搜索框 |
| ↑↓ | 移动活动栏选中项 |
| PageUp / PageDown | 翻页选择 |
| Enter，左栏 | 转到右栏 |
| Enter，右栏 | 恢复选中 session，或新建 session |
| Ctrl+P | pin / 取消 pin 当前项目或 session |
| Ctrl+R，左栏 | 修改项目显示名称；清空名称恢复目录默认名称 |
| Ctrl+Y（Yank） | 复制选中项目的 cwd；全局右栏选中会话时复制其所属项目的 cwd |
| Esc | 从子步骤返回，或关闭主界面 |

复制后保留界面并显示提示，不复制 session 的 JSONL 文件路径。“所有项目”没有实际目录，需选中具体项目或右栏会话才能复制。

已移除独立的“打开目录”功能；仅“所有项目 → 新建会话”保留目录确认步骤。目录输入步骤支持 `~`、绝对路径和相对于打开界面时 cwd 的路径：`↑↓` 选择候选目录，`Tab` 补全 / 进入候选目录，`Enter` 使用输入框中的目录。不存在的目录不会自动创建。

顶部两个搜索框独立。项目选择改变时清空右侧搜索；仅切换焦点不清空。

## 搜索和排序

- 左侧仅按项目显示名称、完整目录路径模糊搜索，不匹配 session 名称。
- 右侧按 session 名搜索；未命名会话使用首条消息作为标题回退，没有消息时使用短 ID。
- “所有项目”表示全局 session 范围，不受左侧项目筛选范围限制。
- 不搜索 session 正文，不支持正则语法。
- “所有项目”“新建会话”是固定入口，始终第一，不能 pin。
- 其他条目先过滤，再按 pin 优先、最近使用时间降序排列；pin 条目也会被搜索过滤掉。
- 最近使用以实际创建 / 恢复时间为准，未记录访问时间时使用会话更新时间回退。

## 创建和恢复

- 具体项目下新建，使用该项目 cwd。
- “所有项目”下新建，先确认目录，默认当前 cwd。
- 恢复 session 通过 Pi 正式 session 替换 API 完成，同时重建目标目录的工具和项目上下文，保留 Pi 的项目信任流程。
- 正在生成内容时显示可取消的等待界面；Esc 只取消打开切换器，不中止正在生成的任务。
- 当前目录的新会话遵循 Pi 的延迟持久化：开始聊天前可能还没有 session 文件。
- 跨目录新建通过 Pi 公共 API 生成并序列化合法的空 session 快照，再执行正式恢复。只包含一个非模型上下文的 `pi-go-created` 条目，不伪造用户消息或触发模型请求。
- 使用 `--no-session` 时可以打开界面，但不支持跨目录新建。

## 数据和存储范围

项目别名、pin 和访问时间保存到：

```text
<Pi agentDir>/pi-go/state.json
```

CLI 默认是 `~/.pi/agent/pi-go/state.json`；支持 `PI_CODING_AGENT_DIR`。

自动列出 Pi 默认历史以及当前 session 存储目录。其他平铺 session 存储目录可显式加入状态文件的 `extraSessionDirs`，例如：

```json
{
  "version": 1,
  "projects": {},
  "sessions": {},
  "extraSessionDirs": ["/absolute/path/to/session-store"]
}
```

请保留文件已有项目和会话元数据，不要用示例覆盖它。额外目录用于发现历史，不自动改变新会话的存储策略。显式设置的当前平铺存储目录会在跨目录新建时保留；默认存储则使用目标项目分组目录。

写入使用跨进程锁和原子替换。损坏或未知版本状态不会被静默覆盖。进程异常退出可能留下 `state.json.lock/`：核对其中 `owner.json` 的进程已经结束后再手动移除锁目录；插件不会仅凭超时删除其他进程的锁。
