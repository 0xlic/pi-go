# pi-go

Pi 的双栏项目 / session 切换器。第一版已实现，基于 **Pi 1.1.0、Node.js 22+** 验证。

## 快速试用

在插件目录执行：

```bash
pi -e ./index.ts --g
```

已有会话中，加载插件后输入：

```text
/go
```

若已有会话尚未加载插件，请先全局安装，再在会话内执行 `/reload`。

## 全局安装

```bash
pi install git:github.com/0xlic/pi-go
pi --g
```

从公开 GitHub 仓库安装，Pi 管理远程源码，不依赖本地开发目录。更新插件：

```bash
pi update git:github.com/0xlic/pi-go
```

已有会话更新后执行 `/reload`。

Pi 扩展原生只支持长参数，因此启动入口是 `--g`，不是 `-g`。不修改系统 `pi` 命令，也不自动安装 shell 包装层。

`--g` 会保留一次打开意图：若加载期间会话被其他扩展替换，旧任务会取消，并在新会话重试。只有选择器成功打开后才消费意图；之后关闭或切换会话不会再次自动打开。

## 临时会话

- 统一使用 `/go`：面板默认选中“临时会话”，左栏按 `Enter` 创建时间戳工作区并切换到新会话，按 `Tab` 进入已有临时会话列表。没有历史时也保留此入口。已移除 `/temp` 命令。
- 工作区仍位于 `getAgentDir()/pi-temp-sessions/YYYY-MM-DD_HH-mm-ss`（默认 `~/.pi/agent/pi-temp-sessions`）。JSONL 使用 Pi 默认的项目会话存储，不写入工作区内部。
- 不再根据 Home 目录自动创建临时会话；启动时可用 `--g` 打开统一面板。
- `/go` 中选中“临时会话”分组后按 `Ctrl+K`，选择最近一天、一周、一个月、一年或全部，再确认删除。这些范围指**最近创建**的工作区，不是早于该时间的工作区。
- 清理会永久删除工作区全部文件及其默认存储中的会话记录，兼容旧工作区内部的记录及 sessions 根目录的 JSONL；工作区已删除时，也会按相同时间范围清理残留历史。跳过当前工作区和当前会话。无法检测其他 Pi 进程，清理前请关闭相关会话。
- 若原先安装了独立的 `pi-temp-session`，请先卸载或禁用，避免重复自动创建。

## 界面和快捷键

```text
项目 › 项目名称 / 目录路径      │ 会话 › 会话名称
Tab 切换 · ↑↓ 选择 · Enter 新建会话 · Esc 取消
Ctrl+P pin · Alt+↑↓ 移动置顶 · Ctrl+R 重命名 · Ctrl+Y 复制路径
───────────────────────────────┼──────────────────────
临时会话                       │ ★ 交互设计
★ pi-go                        │   修复搜索
  another-project              │
```

| 按键 | 功能 |
|---|---|
| Tab / Shift+Tab | 切换活动栏和搜索框；当前范围没有会话时不可切入右栏 |
| ↑↓ | 移动活动栏选中项 |
| PageUp / PageDown | 翻页选择 |
| Enter，左栏 | 在选中项目直接新建；临时会话分组新建临时会话；置顶会话分组转到右栏 |
| Enter，右栏 | 直接恢复选中 session；无匹配会话时不执行操作 |
| Ctrl+D | 删除选中的具体项目或会话（需确认）；虚拟分组不支持删除 |
| Ctrl+K，临时会话分组 | 选择范围并确认清理临时工作区及历史记录 |
| Ctrl+P | pin / 取消 pin 当前项目或 session |
| Alt+↑ / Alt+↓ | 在置顶组内移动当前 pinned 项目或会话，保存顺序 |
| Ctrl+R，左栏 | 修改项目显示名称；清空名称恢复目录默认名称 |
| Ctrl+Y（Yank） | 复制选中项目的 cwd；全局右栏选中会话时复制其所属项目的 cwd |
| Esc | 从子步骤返回，或关闭主界面 |

复制后保留界面并显示提示，不复制 session 的 JSONL 文件路径。虚拟分组没有实际目录，需选中具体项目或右栏会话才能复制。

已移除“所有项目”和独立的“打开目录”入口。

顶部两个搜索框独立。项目选择改变时清空右侧搜索；仅切换焦点不清空。Enter 提示随当前选中项变化：左栏显示“新建会话”，临时会话分组显示“新建临时会话”，右栏显示“恢复会话”，置顶会话分组显示“选择会话”；无可执行操作时隐藏。项目没有会话时焦点留在左栏，并隐藏 Tab 切换提示；仅会话搜索无匹配时仍可留在右栏修改搜索词。

## 删除项目与会话

- 在具体项目或会话上按 `Ctrl+D`，删除会话的确认框默认选“是”，`Enter` 执行；`Tab` 可切到“否”，`Esc` 取消。选中项使用中括号和背景高亮，“是”以红色显示。
- 删除项目会清理所有存储目录中属于该项目 cwd 的会话（不受搜索或 pin 过滤影响），并移除项目元数据。
- 清理成功后再次单独询问是否删除项目文件夹及其全部内容。默认“否”，直接 `Enter` 或 `Esc` 保留文件夹；必须先 `Tab` 再 `Enter` 才会删除文件夹本体。删除不可恢复。
- “置顶会话”“临时会话”等虚拟分组不能删除；右栏具体会话仍可删除。
- 为防止正在使用的会话被重新写回，不允许删除当前会话或包含当前会话的项目，请先切换到其他项目 / 会话。不允许删除根目录、用户主目录、符号链接项目，或包含当前 cwd、当前会话、pi-go 状态文件的文件夹。

## 【置顶会话】虚拟分组

- 有会话被 pin 时，左侧自动出现 **【置顶会话】**，汇总所有项目的置顶会话，并标明所属项目。
- 置顶会话仍保留在原所属项目中，不复制或迁移会话。两个视图都支持 `Alt+↑ / Alt+↓`，共享保存的置顶顺序；在任一视图调整后，另一视图同步体现对应顺序。
- 最后一个实际会话取消 pin 后，分组自动消失；不存在的会话遗留 pin 元数据不会让空分组出现。
- 分组始终置顶，支持 `Alt+↑ / Alt+↓` 与置顶项目交换位置，顺序会保存；不能取消 pin 或重命名。
- 项目搜索仅按分组名称匹配它，不匹配其下的会话名称；右侧可搜索置顶会话名称。
- 分组没有 cwd。左栏不能复制分组路径；右栏选中会话时，`Ctrl+Y` 复制其真实项目 cwd。在此分组左栏按 Enter 转到右栏恢复会话；如需新建，请选择具体项目。

## 搜索和排序

- 左侧仅按项目显示名称、完整目录路径模糊搜索，不匹配 session 名称。
- 右侧按 session 名搜索；未命名会话使用首条消息作为标题回退，没有消息时使用短 ID。
- 临时会话分组固定排在最顶部，高于置顶项目和置顶会话分组；仍按项目搜索词过滤。搜索后自动选择匹配项目，无需先按 ↓。
- 不搜索 session 正文，不支持正则语法。
- 右栏只列选中项目或分组的已有会话，默认选中首项，搜索项目后 Tab → Enter 即可恢复，无需再按 ↓。无匹配项目时两栏显示空状态。
- 其他条目先过滤，再按 pin 优先排列；pin 条目也会被搜索过滤掉。
- 未手动排序的置顶组默认按最近使用排列。用 `Alt+↑ / Alt+↓` 调整后，置顶组保持手动顺序，不受后续访问时间影响；普通条目仍按最近使用排序。
- 搜索或具体项目范围内，只与相邻可见置顶条目交换位置，隐藏条目的位置不变。移动后保留焦点、选中项和搜索词，不更新访问时间。
- 新 pin 或取消后重新 pin 的条目排在已有手动排序的置顶项之后；取消 pin 清除其手动位置。
- 最近使用以实际创建 / 恢复时间为准，未记录访问时间时使用会话更新时间回退。

## 创建和恢复

- 新建或恢复成功后，自动将目标项目 cwd 复制到剪贴板（恢复当前会话也会复制），不复制 session 文件路径；取消或失败时不复制。
- 支持 macOS、Linux 和 Windows；Windows 使用 PowerShell Unicode 编码传输，支持中文、空格及特殊字符路径。Ctrl+Y 使用同一复制实现。剪贴板不可用时仅显示警告，不影响已完成的会话切换。
- 具体项目下新建，使用该项目 cwd。
- 恢复 session 通过 Pi 正式 session 替换 API 完成，同时重建目标目录的工具和项目上下文，保留 Pi 的项目信任流程。
- 正在生成内容时显示可取消的等待界面；Esc 只取消打开切换器，不中止正在生成的任务。
- 当前目录的新会话遵循 Pi 的延迟持久化：开始聊天前可能还没有 session 文件，因此不会作为已有会话条目出现在选择器中。
- 跨目录新建通过 Pi 公共 API 生成并序列化合法的空 session 快照，再执行正式恢复。只包含一个非模型上下文的 `pi-go-created` 条目，不伪造用户消息或触发模型请求。
- 使用 `--no-session` 时可以打开界面，但不支持跨目录新建。

## 失效条目和刷新

每次重新打开 `/go` 都扫描历史并检查项目目录、session 文件是否实际存在；已删除或不可访问的项目，以及文件已删除的会话，不再显示，即使 `state.json` 还保留 registered、pin、别名或访问记录。

`state.json` 不是会话列表缓存：pin / 取消 pin、手动排序、重命名、成功创建 / 恢复以及启动时打开已有会话会更新它。单纯打开选择器不会清除元数据，避免临时离线磁盘丢失 pin 或别名；目录恢复可访问后会重新显示。列表打开期间不监视文件系统，外部清理后请关闭并重新运行 `/go`。

## 数据和存储范围

项目别名、pin、置顶手动顺序和访问时间保存到：

```text
<Pi agentDir>/pi-go/state.json
```

CLI 默认是 `~/.pi/agent/pi-go/state.json`；支持 `PI_CODING_AGENT_DIR`。

自动列出 Pi 默认历史以及当前 session 存储目录。其他平铺 session 存储目录可显式加入状态文件的 `extraSessionDirs`，例如：

```json
{
  "version": 1,
  "projects": {},
  "sessions": {},
  "extraSessionDirs": ["/absolute/path/to/session-store"]
}
```

请保留文件已有项目和会话元数据，不要用示例覆盖它。额外目录用于发现历史，不自动改变新会话的存储策略。显式设置的当前平铺存储目录会在跨目录新建时保留；默认存储则使用目标项目分组目录。

写入使用跨进程锁和原子替换。损坏或未知版本状态不会被静默覆盖。进程异常退出可能留下 `state.json.lock/`：核对其中 `owner.json` 的进程已经结束后再手动移除锁目录；插件不会仅凭超时删除其他进程的锁。
