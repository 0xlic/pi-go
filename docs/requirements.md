# pi-go 需求文档

状态：v0.1.0 初版已实现。第 9 节尚未单独确认的交互细节暂采用建议默认值；使用方法见 [README](../README.md)。

## 1. 目标

提供 Pi 内的项目与会话选择器，快速切换工作目录（cwd）和 session，并创建或恢复 session。

支持两种使用场景：

1. 启动 Pi 时直接进入 pi-go 操作界面。
2. 在已有 Pi 会话中打开同一界面，切换项目与会话。

切换目标是完整的项目会话环境，不是仅调用 `process.chdir()`。恢复 session 后，cwd、工具工作目录和项目相关资源应与目标环境一致。

## 2. 入口

- 原生启动入口：`pi --g`。
- 会话内入口：`/go`。
- 用户最初期望的 `pi -g`：当前本机 Pi 1.1.0 的扩展参数 API 不支持注册短参数别名；若需要该形式，使用可选 shell 包装层转译为 `pi --g`，不作为插件核心实现前提。
- pi-go 应全局安装，避免在不同 cwd 中无法找到插件。
- 启动参数每次进程启动仅触发一次，恢复、新建或重载不能反复打开界面。
- 非交互模式不得打开自定义终端界面。

## 3. 界面

视觉参考：Pi 原生 `/resume` 会话选择界面。

参考 Pi resume 的边框、主题和列表样式，不照搬其单栏布局或全部快捷键。

界面从上到下：

1. 两个搜索框：左侧项目搜索、右侧会话搜索，中间竖线分隔。
2. 快捷键说明。
3. 左右分栏条目：左侧项目，右侧 session。

```text
项目搜索…                   │ 会话搜索…
Tab 切换栏 · ↑↓ 选择 · Enter 打开 · Esc 取消 · …
────────────────────────────┼────────────────────────────
所有项目                    │ ＋ 新建会话
📌 pi-go                    │ 📌 插件交互设计
   example                  │    修复搜索问题
```

### 3.1 焦点与选择

- `Tab` 在左右栏间切换。
- 输入作用于当前活动栏的搜索框。
- `↑↓` 切换当前活动栏的条目。
- 左侧选中项目发生变化时，清空右侧搜索框内容并刷新右侧列表。
- 仅切换活动栏、不改变项目时，不清空右侧搜索。
- 明确显示活动栏、选中项和 pin 状态。
- 搜索和上下移动只改变选择，不直接切换真实 cwd/session；确认后才执行。

## 4. 项目

- 每个项目对应一个 cwd。
- 默认显示名称是目录最后一级。
- 支持重命名；名称是显示别名，不修改实际目录。
- 支持 pin 和取消 pin。
- 项目搜索为空时，左侧第一项为“所有项目”；输入非空搜索词后隐藏该入口，自动选择匹配项目。无匹配项时显示空状态，不回退全局会话。
- “所有项目”是虚拟范围，不是实际 cwd，不可 pin 或重命名。
- 同名项目不能合并，路径用于区分。
- 项目至少能从已有 session 的 cwd 中发现；收藏、手动登记和新增目录的具体入口待确认。

### 4.1 【置顶会话】虚拟分组

- 任意实际会话被 pin 时，自动产生名为“【置顶会话】”的虚拟项目范围，包含所有项目的 pinned sessions。
- 没有实际 pinned session 时自动消失；遗留 pin 元数据不作为产生空分组的依据。
- pinned 会话同时可见于原所属项目及【置顶会话】，不会迁移或复制。两个视图均可 Alt+↑ / Alt+↓ 排序，共享同一会话的保存顺序，所属项目不变。
- 分组始终 pinned，可用 Alt+↑ / Alt+↓ 与实际 pinned 项目交换位置并保存，不能取消 pin、重命名或映射为 cwd。
- 左侧只按分组名称匹配，不使用其下会话名称匹配。右侧会话搜索及排序规则不变，并显示所属项目。
- 分组自身不可复制路径；选中其下实际会话后，复制该会话所属项目 cwd。新建会话需确认目录。

## 5. 会话

- 右侧固定第一项为“新建会话”。
- 选中具体项目时，列出该项目的 sessions。
- 选中“所有项目”时，列出全局 sessions。
- 支持恢复选中的 session，并进入其对应 cwd。
- 支持在目标目录创建新 session。
- 支持 pin 和取消 pin。
- “新建会话”是动作，不可 pin。
- 全局列表应能区分会话所属项目。
- 无名称的 session 必须有可辨识的展示回退；其搜索范围见待确认项。

## 6. 搜索

- 两个搜索框各自保存输入。
- 支持模糊搜索。
- 项目支持目录路径和项目名称检索。
- 会话支持会话名称检索。
- 左侧仅匹配项目名称和目录路径，不通过 session 名称命中项目。
- 选中“所有项目”时，右侧 session 名搜索作用于全局会话。
- pin 条目也受搜索过滤，不得因 pin 而强制显示。
- 不要求第一版支持正则或引号精确搜索；截图中的这些能力只是视觉参考。

两个搜索框职责独立：左侧搜索项目，右侧搜索会话；全局范围语义见第 9 节。

## 7. 排序

- 普通项目和 session 按最近使用排序；置顶组默认使用最近使用排序，手动调整后使用保存的顺序。
- pinned 项目位于普通项目之前；pinned session 位于普通 session 之前。
- “所有项目”仅在项目搜索为空时位于第一项；“新建会话”在存在有效项目范围时位于右侧第一项，无匹配项目时不提供该动作。
- 搜索过滤后仍遵循 pin 优先及手动顺序 / 最近使用排序。
- 已 pin 的项目或会话支持 Alt+↑ / Alt+↓，在置顶组内与相邻可见置顶条目交换位置，隐藏条目不挪位。
- 手动顺序持久化且优先于访问时间；移动不改变当前选择、搜索或访问记录。
- 未 pin 条目与虚拟入口不能移动；置顶组首尾不循环。取消 pin 清除手动位置，新 pin 或重新 pin 排在已有手动排序条目之后。
- 同时间条目使用稳定次级排序，避免列表抖动。

“最近使用”推荐定义为用户成功创建或恢复会话的时间，而不是搜索、浏览或文件更新时间；未记录过访问时使用 session 更新时间回退。该定义待确认。

## 8. 安全与体验

- 取消选择不改变当前 cwd 和 session。
- 不自动删除或覆盖已有 session。
- 每次打开 /go 检查项目目录及 session 文件；失效项目和会话不显示，state.json 的 registered/pin/别名不绕过存在性检查。
- 不自动删除旧元数据或会话文件，避免离线磁盘丢失设置；未写盘的当前空会话不伪造为已有会话。打开界面后才失效的目标，在操作前检查并提示。
- 不绕过 Pi 的项目信任或 session 切换取消机制。
- 切换必须使用安全的 session 替换路径，不在不允许的生命周期回调里直接调用命令专用 API。
- Pi 正在生成内容时，等待空闲后再打开切换器或执行切换，不默认中止正在进行的任务。
- 支持中文输入、宽字符、窗口缩放和键盘操作。
- 第一版不包含删除 session、删除项目、会话内容全文搜索、自动扫描整个文件系统。

## 9. 待确认事项及建议默认值

以下为设计建议，不应视为用户已经确认。

| 编号 | 问题 | 建议默认值 |
|---|---|---|
| Q1 | 左侧是否通过 session 名搜索项目？ | 不支持（已确认）；左侧仅搜索项目名称和目录路径，右侧搜索 session 名称 |
| Q2 | 项目搜索时是否保留“所有项目”？ | 不保留（已确认）；非空搜索只展示实际匹配项目，唯一结果可直接 Tab 搜索会话 |
| Q3 | 在“所有项目”下选择“新建会话”用哪个目录？ | 打开目录选择/输入步骤，默认当前 cwd，并明确展示路径 |
| Q4 | 如何新增没有历史 session 的项目？ | 通过“所有项目 → 新建会话”确认目标目录；移除独立“打开目录”操作 |
| Q5 | pin、重命名、复制路径快捷键是什么？ | Ctrl+P pin；Ctrl+R 项目重命名；Ctrl+Y（Yank）复制项目 cwd（已确认替换原打开目录功能） |
| Q6 | 最近使用怎么定义？ | 成功创建/恢复的时间；无记录时回退到 session 更新时间 |
| Q7 | 无名称 session 如何显示和搜索？ | 显示 Pi 标准回退标题；允许按这个显示标题搜索，但不做全文搜索 |
| Q8 | 启动时默认项目是什么？ | 当前 cwd 对应项目，不存在则“所有项目”；焦点默认左栏 |
| Q9 | 项目来源和可见范围是什么？ | 当前 cwd、Pi 默认存储中的历史项目、用户手动登记项目；额外 session 存储目录须显式配置 |

### 9.1 已确认调整：复制项目路径

- Ctrl+Y 复制选中项目的 cwd，而不是 session 保存文件的路径。
- 右栏选中会话时，复制该会话所属项目的 cwd，包括“所有项目”范围内的会话。
- 没有具体项目或会话可供选择时提示，不复制启动目录作为隐式回退。
- 成功/失败提供提示；复制后不关闭界面、不改变 cwd/session 或访问排序。
- 独立“打开目录”功能移除；新建会话的目录确认步骤保留。

## 10. 验收场景

1. `pi --g` 启动后只打开一次界面；`/go` 能在已有会话中打开相同选择器。
2. 顶部两个搜索框、快捷键行和左右列表符合布局要求。
3. Tab 切换栏，↑↓ 只移动活动栏选择；更换项目清空 session 搜索。
4. 项目仅可按名称和目录路径模糊检索；输入仅匹配会话名称的关键词不会命中项目。
5. 具体项目下仅搜索该项目会话；“所有项目”支持 session 名全局搜索。
6. 非空项目搜索隐藏“所有项目”并自动选择匹配项；清空搜索恢复该入口；无匹配项不回退全局。pin 分组优先且受过滤影响。
7. 项目重命名后名称持久化，实际 cwd 不改变。
8. pin 状态和访问时间重启后仍保留。
9. 恢复跨项目 session 后，工具实际工作目录和项目上下文与目标目录一致。
10. 在已有及无历史的新目录中均可创建新 session；跨目录创建已通过真实 Pi SDK 集成测试，真实终端体验仍需手动验收。
11. Esc 退出选择器不改变当前环境；切换被取消时不记录成功访问。
12. 缺失目录、损坏 session、空结果和窄窗口均有可理解的反馈。
